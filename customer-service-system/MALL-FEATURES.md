# 商城运营功能使用说明

本机入口：http://127.0.0.1:35173/ 。使用原有电商平台账号登录即可。

## 后台菜单

点击一级菜单可以展开或收起其子菜单；顶部左侧按钮可以折叠整个侧栏。

| 分组 | 功能 |
|---|---|
| 智能运营助手 | 侧栏顶部独立入口；业务分析及后台业务操作，核对差异后确认执行；禁止账号与角色变更 |
| 智能分析 | 运行历史、诊断报告、观测看板、语义检索 |
| 用户管理 | 会员查询、账号启用/禁用、地址、收藏、浏览足迹、搜索历史、意见反馈回复 |
| 商场管理 | 省市区数据、品牌、分级类目、商品归属、订单、售后、常见问题、搜索关键词 |
| 商品管理 | 原有商品列表、编辑与上架、商品评论；上架表单增加品牌和已有类目选择 |
| 推广管理 | 首页广告、优惠券、商品专题、团购规则、团购活动 |
| 系统管理 | 原有账号管理和操作日志，新增通知发布、运营角色和文件列表/上传 |
| 配置管理 | 商城资料、运费、未付款超时取消、发货超期自动收货、评价期限、下单限制、小程序展示资料 |
| 统计报表 | 按日期查看用户新增、有效订单、商品销售，支持导出当前结果 |
| 服务入口 | 腾讯云、阿里云、微信支付等官网入口 |

账号禁用和商城配置仅管理员可操作。运营角色控制新增商城模块的访问权限，不改变原有管理员、运营、买家三种基础身份。角色停用后，其绑定运营账号失去这些新增模块的访问权限。管理员账号资料与密码在后台设为只读，不提供独立的服务器管理员登录入口。

## 功能如何生效

1. **品牌与类目**：先在商场管理维护资料，再在商品上架表单或“商品归属”中关联商品。品牌显示在商品详情中；类目关联会同步商品的主类目。已有商品类目在首次加载时自动接入。
2. **广告、关键词与专题**：在后台保存并启用后，显示在买家商品首页。广告可关联商品或 HTTP/HTTPS 链接；专题可以选择多个商品。
3. **优惠券**：设置减免、门槛、总量和有效期；立即购买和购物车均可选择。待付款时占用，付款时核销，超时或主动取消未付款订单时释放。修改规则对新领取生效，已领取的券保留原规则；已付款订单退款不返还已核销的券。
4. **运费**：按每次购物车结算或立即购买收取一次基础运费；商品小计达到包邮门槛时免运费。拆成多个商品订单时，优惠和运费按金额分摊并保存；已有订单保持原金额。
5. **团购**：每次参团购买一件，团购价含运费、不叠加优惠券。参团时预留库存并创建“等待成团”的演示订单，人数达标后才可发货。后台每分钟处理到期团，取消未成团订单并返还库存；打开团购页也会处理到期团。活动页面每分钟刷新。
6. **反馈与公告**：买家可以提交反馈并查看回复。“公告与帮助”显示适用人群的通知和常见问题。
7. **用户行为**：只记录买家实际搜索和浏览；相同操作在一分钟内重复加载会去重。不会把 litemall 的示例会员、商品或订单导入你的平台。
8. **行政区域**：省市区数据为 litemall 提供的参考数据，不保证反映最新行政区划。地址表单支持三级选择，也保留手动填写。
9. **订单期限**：下单后先待付款，默认30分钟未付款取消并返还对应规格库存和优惠券；默认发货7天自动收货，处理中售后跳过；收货后默认7天内可评价。任务每分钟检查，付款时也校验截止时间。同次结算的商品一起付款或取消，重复操作不会重复扣减/返还库存。
10. **后台业务助手**：可新建/编辑多规格商品、维护价格库存与上下架、品牌类目和归属、订单发货或取消待付款结算、售后审核/换货发货/消息、评价与反馈回复、买家私聊、推广资料增删改、通知已读、风险检查、业务日志回退、知识库同步和商城配置。先展示方案与差异，确认后复核当前账号业务权限、实时数据和原有业务规则，在同一数据库事务中执行并记录操作日志。知识库同步单独提交。禁止创建、修改或删除用户、管理员、运营账号、密码、身份、角色和授权；日志回退也不能绕过。模型不获得任意 SQL、HTTP 或服务器执行权限。文件上传需用户提供文件，付款退款仍沿用本地模拟业务。

所有下单仍沿用平台原有的**演示订单**方式。本次没有接入实际支付、退款、短信或云存储账号；服务入口打开对应官网。小程序页面仅保存展示资料，请勿在其中填写密钥。

## 数据与源码

- 扩展数据保存在本平台数据库的 `mall_*` 新表中，原有用户、商品、订单表继续使用。
- 所有新增后台接口均校验登录和对应模块权限；会员状态操作额外要求管理员身份。
- 运营资料和配置修改写入原有操作日志。新增资料的日志保留前后内容，不提供自动回退。
- 新接口：`backend/app/api/mall.py`；事务和业务规则：`backend/app/services/mall_service.py`。
- 字段白名单：`backend/app/services/mall_registry.py`；新表：`backend/app/models/mall.py`。
- 侧栏：`frontend/src/components/CommerceSidebar.vue`；运营页面：`frontend/src/views/CommerceAdmin.vue`。
- 相关回归位于 `backend/tests/test_checkout_lifecycle.py`、`test_mall_agent.py` 和 `frontend/tests/checkout.test.js`，使用隔离数据库验证交易与配置确认。
- 行政区参考数据的来源与 MIT 授权见同目录 `LITEMALL-NOTICE.txt`。

本次只修改本地项目，未提交 Git、上传镜像或部署线上服务。
