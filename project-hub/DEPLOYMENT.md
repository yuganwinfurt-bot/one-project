## 部署前要确认

1. **域名与站点一致**：当前 ICP 截图中是 `yuganwinfurt.top` 和 `43.142.117.116`。确认 DNS 实际解析、服务器公网 IP、ICP 网站名称和服务项目与备案信息一致；PDF 中的 `www.yuganwinfurt.top` 只有在 DNS、证书和实际站点都就绪后才加入网站访问地址。使用 HTTPS，检查证书有效期；公安备案申请中的“网站访问地址”填真实可访问的完整 URL。当前外部访问检查工具未能确认站点可达，因此部署后必须从外网实测。
2. **先核对现有应用**：2026-10-13 服务器截图显示这台机器是 Ubuntu Server 24.04、4 核 4 GB，已运行 Hermes Agent。安装本站前先只读检查现有的 Nginx/Caddy、80/443/8030 端口、证书与站点目录，避免覆盖 Hermes Agent 的服务配置。
3. **管理端保持内网**：项目首页只转发身份状态、登录和退出三个接口。Agent 必须在服务器本机运行并使用与 RAG 相同的管理员账号配置；把 `PROJECT_HUB_AGENT_API_URL` 指向本机 Agent（默认 `http://127.0.0.1:8020`）。不要把 Agent/RAG 管理端口或其他 API 路由对公网开放。
4. **公网只能到统一入口**：反向代理仅转发到本项目 `127.0.0.1:8030`。`rag-assistant` 的 8000 端口、`yugan-agent` 原管理网页的 8020 端口、Ollama 的 11434 端口以及数据库与上传目录都不应对公网开放。示例反向代理见 [Nginx 配置](deploy/nginx.example.conf)，独立服务模板见 [systemd 单元](deploy/project-hub.service.example)。
5. **账号与密钥**：管理员账号、密码哈希和签名密钥继续只配置在 Agent/RAG 服务端；首页不会保存用户输入的密码。模型 API Key 按各应用现有实现保存在用户浏览器本地，不由首页转发。
6. **公开 AI 服务的备案字段**：当前公开页仅为项目介绍。若未来开放网页内在线问答，公安备案表格的“是否提供生成式 AI 服务”应按实际上线功能核实；公开 AI 可能涉及生成式 AI、深度合成内容标识、算法备案等规则，是否需要额外程序要按具体功能和主管部门口径确认。

## 公安备案提交与通过后

PDF 记载的网站开通日期是 **2026-09-22**。如果该日期就是实际上线日，按指引“开通后 30 日内”的时间要求应尽快提交；以实际开通记录及公安平台要求为准。ICP备案与公安联网备案是两项不同流程，不能互相替代。

在[全国互联网安全管理服务平台](https://beian.mps.gov.cn/)填写主体和网站资料；证件、联系人、域名证书及腾讯云提供的备案数据码等材料只在备案流程中使用。网站需在审核期间正常可访问。提交时应说明真实服务内容：当前公网网页仅展示项目介绍，Agent 与 RAG 管理操作页面仍仅在本机使用。若后续增加登录和在线问答，应按实际功能更新说明。

通过后按照平台返回的真实公安备案号、查询链接和官方提供的展示代码更新页脚；若平台提供图标，也使用该图标，不自行绘制备案标识。重新构建并上线后，在**实际公网首页**检查：域名、HTTPS、项目内容、ICP备案号、公安备案号及其可点击查询链接；从外网确认原管理端口不可达。ICP备案服务项目或网站名称变化时，按备案渠道办理变更。
