# 项目作品集公开介绍

作品集包含四个应用：电商分析平台、客服工单系统、Agent 智能体和 RAG 知识库。本资料仅说明项目功能，不包含账号口令、个人身份、私有文件或真实客户资料。

## 电商分析平台

使用 Vue 3 与 FastAPI，提供商品浏览、购物车、订单、支付流程、收藏、评价、售后、消息及运营管理。智能运营助手查询业务记录，并自动检索电商分析平台和客服工单系统的知识库。买家端有独立手机布局。需要修改业务数据时，以应用内确认和实际执行结果为准。

## 客服工单系统

源码：https://github.com/yuganwinfurt-bot/ai-customer-service-agent

使用 Next.js、React、TypeScript、FastAPI 与 SQLite。买家默认由 AI 接待，可申请人工；申请后停止自动回复并通知工作人员。工单工作台提供聊天、知识管理、分类分析、指标明细和符合条件工单的批量处理。客服和用户均可结束人工服务并保留沟通记录。聊天结束不等于退款或换货业务完成。

工单与电商平台的咨询、售后申请和聊天记录同步。工作人员使用电商平台的管理员或运营账号登录，模型跟随 Agent 控制台配置。启用知识条目和匿名统计报表可手动同步到 RAG 的“客服工单系统”知识库。

## Agent 智能体

Python 与 FastAPI 提供任务会话、工具注册、工作区、工作流及审批。模型在已配置的权限范围内选择工具，程序校验后执行并保留结果。完整本地版本包含文件、命令和常用桌面操作。介绍页链接到源码；本机入口进入本机控制台。

## RAG 知识库

使用 Python、FastAPI、Ollama 和向量索引管理资料，支持 PDF、DOCX、TXT、Markdown、CSV，文档分片后建立索引。提问时先检索资料，再生成附有来源的回答；多个知识库可组成一个项目。电商和客服同步的数据是手动快照，不能冒充实时业务状态。

## 四个应用如何协作

电商平台保存交易及售后业务，客服工单系统承接咨询与人工协作，Agent 提供模型配置和执行能力，RAG 提供检索依据。项目主页展示四个应用的介绍、GitHub 源码和可用入口；管理权限仍由各应用验证。本机入口不会自动变成公网入口。统一启动器管理本机服务，关闭窗口会停止已验证属于这些项目的服务及子进程。
