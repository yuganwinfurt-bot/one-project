# 项目实验室公开资料

这是两个独立的学习项目。公开网页用一个入口展示它们各自的作用，并提供经过筛选的技术问答。这里不包含个人经历、身份资料、联系方式、私有文件或设备控制能力。

## Agent 智能体

Agent 智能体是一个 Python 项目。它用 FastAPI 提供网页与 API 入口，支持不同模型供应商、会话记忆、工具注册、工作流和审批。完整的本地开发版可以操作工作区、运行工具，并有电脑操作功能；这些功能不属于公开演示。公开演示只使用隔离的 Agent 实例，工具列表为空，只根据经过筛选的知识库回答技术问题。

Agent 负责理解问题、组织回答和管理执行步骤。工具调用的意思是模型选择一个由程序明确注册的功能，程序核对参数和权限后才运行；模型本身不能凭文字获得操作系统权限。公开版本不注册文件、命令、浏览器、设备或电脑控制工具。

## RAG 知识库

RAG 是“检索增强生成”。文档先被切成较短的片段，再通过向量模型变成可搜索的表示，保存在 Chroma 向量库。收到问题后，系统找出相关片段，再交给语言模型组织答案。项目用 Python、FastAPI、LangChain、LangGraph、Ollama、SQLite 和 Chroma 实现文档管理、检索、问答与来源展示。

RAG 项目原本支持多个知识库和多个对话，可导入 PDF、DOCX、TXT、Markdown 和 CSV。公开入口只访问单独建立的“项目实验室公开资料”知识库，不访问原有的学习资料、上传文件或聊天记录。没有足够相关片段时，应说明资料不足，不能把猜测说成资料结论。

## 两个项目如何连接

访客从 Vue 网页提问。统一后端先向 RAG 的受保护桥接接口发送问题，RAG 只在明确列入白名单的公开知识库检索并回答。选择 Agent 模式时，统一后端再把检索结果作为资料交给隔离的 Agent 实例组织回答。RAG 提供依据，Agent 组织表达。私有项目原有的管理接口不通过统一后端转发。

两个项目的公开模式分开运行。RAG 桥接接口需要内部令牌，Agent 公开实例不注册工具，网页 API 设置输入长度和频率限制。公开网页不展示个人身份、手机号、邮箱或住址。
