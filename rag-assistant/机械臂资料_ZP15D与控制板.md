## 1. 用户实物照片确认

### 1.1 ZP15D 舵机

用户照片中有两只舵机的标签清楚写着 `ZP15D`。它们属于杭州众灵科技 ZP 系列单总线数字舵机，适合机器人和机械臂关节。

从公开的众灵资料可确认：

- `ZP` 表示总线舵机系列；型号中的 `15`通常表示约 15 kg·cm 扭矩。
- 供电范围约为 4.8–8.4 V，常见系统电压为 7.4 V。
- 使用单总线串口通信，常用波特率为 115200。
- 每个舵机有 ID，默认 ID 为 `000`，广播地址为 `255`。
- 支持位置控制、位置回读，并可读取温度和电压。
- 常见角度范围为 270°；资料还列出 180°、360°等工作模式可切换。
- 舵机三线通常为：信号线 `S`、电源正极 `+`、电源负极 `-`。线序必须以该批次说明书或板上丝印确认。

### 1.2 25 kg·cm 舵机

用户另一张照片中的舵机标签能看出 `25KG.CM`。这表示该舵机扭矩等级约为 25 kg·cm，约 2.45 N·m，适合底座、肩部等承重较大的关节。

照片没有清楚显示完整型号，暂时不能确认它是否为 `ZP25D` 或同系列其他型号。采购替换件时不能只按“25 kg”判断，必须核对完整型号、轴结构、工作电压和通信协议。

### 1.3 控制板照片判断

用户提供的底座控制板可见以下接口：

- 上方有标号 `0 1 2 3 4 5` 的 6 组三针插座。结合 ZP15D 舵机和三线连接方式，它们更可能是 6 路总线舵机接口；这是照片推测，不能确认是否同时支持普通 PWM。
- 黄色插座丝印看起来是 `TX RX G 5V`，大概率是给外部主控使用的串口接口；实际方向和电平需要测量或查该板说明书。
- 右侧有 `SD1/SA1`、`SD2/SA2`、`SD3/SA3` 等扩展接口，可能用于数字/模拟传感器。
- 底部有电源接线端子、总电源开关和电源调节/检测元件。

白色贴纸遮住了主控芯片，照片没有拍到完整 PCB 型号，因此目前不能确认具体板号、MCU 型号和每个接口的精确针脚顺序。

## 2. 总线舵机通信

众灵资料给出的基本协议特征：

- 单线半双工串口总线。
- 波特率通常为 115200。
- ID 范围通常为 000–254，255 用作广播。
- 位置控制指令格式示例：

```text
#000P1500T1000!
```

含义：向 ID 为 `000` 的舵机发送目标位置 `1500`，运动时间为 `1000 ms`。

常见查询/配置示例：

```text
#000PID!       查询指定 ID 是否存在
#000PVER!      查询版本
#000PRAD!      读取当前位置
#000PRTV!      读取温度和电压
#000PID001!    把 ID 000 修改为 ID 001
#000PULK!      释放舵机扭力
#000PULR!      恢复舵机扭力
```

协议中的 ID、位置和时间字段要求补足固定长度，例如 ID `1` 要写成 `001`，位置 `800` 要写成 `0800`。

## 3. STM32 接入注意事项

1. 舵机电源不能由 STM32 开发板或 USB 直接提供，应使用机械臂配套的约 7.4 V 电源，并确认适配器极性。
2. STM32 控制总线舵机时，需要单线半双工 UART 或等效的收发方向控制，不能只写普通 PWM 输出程序。
3. 如果使用外部 STM32 电源，舵机电源负极和 STM32 地线需要共地。
4. 不要把板上的 `TX`、`RX`、`5V` 直接按普通串口模块连接，先确认它们是主控串口还是舵机总线、信号电平是否兼容。
5. 断电后再插拔舵机线；机械臂上电后大舵机可能突然回到上次目标位置，应先固定机械臂并卸下末端负载。
6. 第一次测试只连接一只舵机，先读取 ID 或发送低风险的小幅位置命令，再连接全部关节。

## 4. 对当前机械臂的初步结论

目前可以确认：这台机械臂至少使用了 ZP15D 总线舵机和一只约 25 kg·cm 的大扭矩舵机，底座内的控制板负责舵机供电、串口/总线连接和扩展接口。它适合使用 STM32 通过 UART 总线控制，并读取舵机位置、温度和电压。

仍需实物照片或原厂资料确认的项目：

- 25 kg·cm 舵机的完整型号；
- 控制板的 PCB 型号和 MCU 型号；
- `0–5` 插座的准确针脚顺序；
- `TX RX G 5V` 接口的实际用途和电平；
- 每个关节对应的舵机 ID、零位和机械限位。

## 6. STM32 主控版本

用户提供的商品截图写明，这套“总线入门版”可选 4 种主控：Arduino、STC51、STM32、ESP32；同时配有 KPZ1 底板、8.4V/3A 适配器，部分套装还包含手柄、蓝牙模块和积木。截图中的 STM32 选项说明的是“主控模块采用 STM32”，舵机型号和总线协议仍由舵机本身决定。

对 STM32 版本，建议按下面的系统结构理解：

```text
STM32 主控模块
      │ UART / 单线半双工
      ▼
KPZ1 底板或控制板
      │ 供电 + 总线信号
      ▼
ZP15D、25 kg·cm 等总线舵机
```

STM32 版本需要重点确认的实物信息：

- STM32 模块的具体芯片型号（例如 STM32F103、STM32F401 等）；
- 模块插在 KPZ1 底板上的排针位置和接口定义；
- STM32 使用的 UART 号、TX/RX 引脚和单线收发方向控制方式；
- 控制板上 `TX RX G 5V` 是否就是给 STM32 的主控串口；
- 出厂时各关节舵机的 ID、零位和动作示例程序。

目前商品截图只能确认“有 STM32 版本”，不能确认具体 STM32 芯片和引脚。要写出可直接烧录的 Keil 工程，还需要拍 STM32 主控模块正面、背面和插在 KPZ1 底板上的接口近照。
