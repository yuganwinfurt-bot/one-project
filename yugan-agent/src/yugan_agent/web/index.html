CAPABILITY / 02

工具系统

工具是模型能实际调用的函数，不是 Skill。这里包含编程、Git、工作区文件、桌面和数据工具；你也可以启停内置工具或添加固定 HTTP 接口。

＋ 添加自定义 HTTP 工具

参数类型支持 string、number、integer、boolean。GET 参数放在查询字符串，POST 参数作为 JSON。只接受 HTTPS；本机地址可用 HTTP。响应最多读取 12 KB，超时 8 秒。工具 Key 保存在项目 .yugan/tools.json。

AUTOMATION / 03

电脑任务工作流

将复杂任务拆分为有序步骤，并结合当前模型与可用工具连续执行。

游客也可以编辑并运行工作流；可用工具会按游客权限过滤，需确认的操作仍会等待审批。

TASK STEPS

任务步骤

步骤保存在当前浏览器；运行时按顺序执行，失败或拒绝后停止。

RUN RESULT

执行记录

填写步骤后运行，结果会显示在这里。
MEMORY / 04

上下文记忆

对话与会话状态保存在本机 SQLite；执行明细只保存在当前浏览器，用于查看模型、知识库检索和工具调用结果，不包含模型内部推理文本。

SESSIONS

会话列表

SELECTED SESSION

会话详情

选择左侧会话查看内容。
WORKSPACES / 06

工作区

查看工作区及其关联会话；管理操作仅对管理员开放。

MODEL / 05

连接模型

在这里保存当前浏览器的 API 模型，并可单独指定识图模型。聊天菜单会读取已保存的 API 模型和 Agent 服务器部署的 Ollama 对话模型。

未单独设置时，图片会交给聊天栏当前选中的模型识别。

API Key 保存在当前浏览器。当前选中模型会同步给本机售后客服服务，供买家AI咨询使用；服务只在内存中保留密钥。

SAVED MODELS

已保存的模型

聊天与售后AI使用当前选中模型。服务重启后，打开控制台或客服工作台即可重新同步；密钥不会显示在列表中。
