# BOSS打招呼助手

修复内容：

- 搜索方案可选择省份，再勾选多个城市；切换省份后已选城市会保留，也可以跨省选择。
- 岗位名称直接作为 BOSS 搜索词；岗位要求只供 AI 匹配。搜索方案只设置求职类型、BOSS 薪资范围和城市。
- AI 岗位细筛支持多条“岗位名称 + 岗位要求”；薪资只在右侧搜索方案中设置一次，不再另加一套 AI 薪资过滤。
- 增加“立即顺序搜索已启用方案”。点击后每完成一个城市和岗位名称的识别，再打开下一条搜索；每条搜索使用独立标签页，前一条的结果不会被下一次搜索覆盖。
- 移除定时搜索和执行时间设置；扩展只会在用户点击手动搜索按钮后开始搜索。
- 搜索和 AI 识别不会代替用户确认投递；原有投递确认设置继续生效。
- 默认 AI 接口预填 DeepSeek URL 与 V4.1 Flash-1017 的 API 模型名 `deepseek-flash`，官方直连请求使用 `reasoning_effort=max`；API Key 需要你自己填写。max 思考强度可能增加响应时间与 token 消耗。
- 简历资料支持上传 PDF，在扩展设置页本机提取文字；识别文本保存在扩展本地存储，AI 调用时发送给你配置的模型接口。扫描版 PDF 暂不支持 OCR。
- “一键根据简历配置岗位”只有在 AI 接口 URL、Key、模型都已填写且 PDF 已解析后才能使用；生成岗位名称和匹配要求并同步 BOSS 搜索词，不改城市、求职类型、薪资和投递规则。
- “AI 招呼语开关”关闭后，岗位筛选仍使用你填写的提示词；沟通由插件点击 BOSS 页面“立即沟通”，招呼语由 BOSS 端“沟通时自动发送招呼语”设置控制。

## 安装

1. 在原插件设置页打开“基础配置”，使用“导出配置”保存 JSON。导出的文件可能含 API Key 和 PDF 提取文本，请只保存在自己的电脑上，不要发给他人。
2. 打开 Edge `edge://extensions/`，先关闭原来的 BOSS 求职助手，避免两个插件在 BOSS 页面重复运行。暂时不要卸载原插件。
3. 打开“开发人员模式”，点击“加载解压缩的扩展”，选择本目录 `boss-ai-helper-local-patched`。
4. 打开修正版设置页，在“基础配置”中导入刚才的 JSON。导入只在本机完成；不要把 JSON 上传到聊天或网盘。
5. 在“基础配置”的“搜索方案”中选择省份和城市，并设置求职类型、BOSS 薪资范围。岗位名称和岗位要求在左侧填写。旧任务的搜索关键词会自动迁移为岗位名称，原有城市会保留。
6. 在“AI 接口”填写 DeepSeek API Key，模型默认是 `deepseek-flash` 并启用 max 思考强度；可先点“测试 API”。随后在“简历资料”上传可复制文字的 PDF，读取完成后点“一键根据简历配置岗位”。

## 使用方式

- 每个搜索方案对应一套共用条件。选省份后勾选城市，切换省份可以继续添加其他城市；不用为每个城市重复设置求职类型或 BOSS 薪资范围。
- 左侧每个启用的岗位名称都会在所选城市中单独搜索；对应的岗位要求供 AI 判断岗位是否匹配。新增或修改岗位名称后，搜索任务会自动同步。
- “打招呼话术提示词”已有默认内容，可以保留不改；它只影响助手调用 AI 生成招呼语时的写法。
- 要使用 BOSS 自己保存的招呼语，请关闭“AI 招呼语开关”，并在 BOSS 端开启“沟通时自动发送招呼语”。
- PDF 简历和补充经历都会用于岗位匹配与 AI 招呼语；PDF 文件在本机解析，只有提取出的文字会在 AI 请求时发往你填写的模型接口。投递时只发送 AI 生成的招呼语，不附带简历图片。
- 一键配置前必须设置 AI 接口 URL、API Key 和模型名。AI 会参考简历、现有岗位画像及搜索偏好生成 3 到 6 个岗位；确认生成后会替换左侧岗位条件并同步搜索词，城市、求职类型、薪资及投递方式保留。
- 立即搜索会按行顺序打开对应城市的 BOSS 搜索页并识别岗位。看到识别结果后仍按插件原有设置确认是否投递。
- 只有手动点击“立即顺序搜索纳入方案”才会开始搜索；没有后台定时触发。
- 浏览器需要保持打开。遇到 BOSS 安全验证时请手动完成；验证期间不要让队列继续跑。

## 回退

回退时，在 `chrome://extensions/` 中关闭或移除“BOSS打招呼助手”，再重新启用旧插件。旧插件配置未被此版本覆盖；若在此版本中修改了配置，可先从设置页导出 JSON 留存。
